Put your image files in this folder, then type their exact file names
(with extension) into the SITE_IMAGES block near the top of index.html:

  BACKGROUND_IMAGE: 'your-background-file.jpg'
  LOGO_IMAGE: 'your-logo-file.png'

Nothing else needs to change - the site reads the names from index.html
and loads the matching file from this assets/ folder automatically.
